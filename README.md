# PearLauncher
## PearLauncher 1.0.0

第一个正式版本。

### 功能一览
- 多实例管理，支持独立游戏目录
- Fabric / Forge / NeoForge / Quilt 一键安装
- 陶瓦联机（房间码联机）
- Microsoft 正版 / 离线账户，支持皮肤上传
- 64×64 皮肤编辑器、Modrinth 资源中心
- 按版本自动选择 Java（远古版自动匹配 Java 8）
- 简体中文 / English 双语界面，首次启动引导
